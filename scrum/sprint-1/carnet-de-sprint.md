# Carnet de sprint 1 

| Membres | Fonctionnalités | Description |
|---|---|---|
| William | Le convoyeur doit être capable de transporter le poids de l'objet. | La structure et le moteur supportent la charge sans déformer la courroie. |
| Khadim | Le convoyeur devrait être capable de mesurer le poids des pièces transportées. | Une pièce de simulation standard peut peser entre 5 et 50 grammes. |
| Djamil | Les bras mécaniques doivent pouvoir déplacer les objets. | Des servomoteurs orientent les bras pour trier et guider les pièces. |
| Emmanuel | Le convoyeur doit arrêter de fonctionner lorsqu'il est renversé ou vide. | Des capteurs coupent le système en cas de basculement ou d'absence de pièce. |
| Emmanuel | Le capteur doit pouvoir détecter s'il y a un objet devant. | Un capteur infrarouge ou de proximité valide immédiatement la présence d'une pièce à l'entrée de la ligne. |
| William | Le convoyeur doit avoir une vitesse constante. | La commande moteur garantit un entraînement fluide et uniforme. |
| William | Le convoyeur devrait inclure un variateur de vitesse ajustable. | La vitesse doit être ajustable diectement dans l'IDE. |
| Djamil | Les bras mécaniques doivent avoir un angle ajustable. | L'angle doit être ajustable diectement dans l'IDE. |
| William | Le convoyeur devrait pouvoir fonctionner des deux côtés. | Le moteur doit être en mesure d'avancer et reculer. |
