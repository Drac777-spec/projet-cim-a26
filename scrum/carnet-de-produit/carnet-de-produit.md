# Carnet de produit

## Fonctionnalités de base du prototype

| Fonctionnalités | Description |
|---|---|
| Le convoyeur doit être capable de transporter le poids de l'objet. | La structure et le moteur supportent la charge sans déformer la courroie. |
| Le convoyeur devrait être capable de mesurer le poids des pièces transportées. | Une pièce de simulation standard peut peser entre 5 et 50 grammes. |
| Les bras mécaniques doivent pouvoir déplacer les objets. | Des servomoteurs orientent les bras pour trier et guider les pièces. |
| La largeur de notre convoyeur dépasse pas 40 millimètres. | L'objet doit pas dépasser 30 millimètres par 30 millimètres. |
| Le convoyeur doit avoir une vitesse constante. | La commande moteur garantit un entraînement fluide et uniforme. |
| Le convoyeur doit être stable et ne pas tomber lors de l'utilisation normale. | Le châssis est équilibré et doté de pieds antidérapants. |
| Le convoyeur doit avoir un bouton de marche et d'arrêt. | Un interrupteur physique permet le démarrage et l'arrêt direct. |
| Le convoyeur doit arrêter de fonctionner lorsqu'il est renversé ou vide. | Des capteurs coupent le système en cas de basculement ou d'absence de pièce. |
| Le convoyeur doit avoir une écran TFT avec une interface utilisateur agréable et simple. | L'écran doit afficher le poids, le type de l'objet et la date et l'heure. |
| Le convoyeur doit avoir des bacs de 100 millimètres par 100 millimètres pour stocker les objets. | Les bacs doivent pouvoir supporter 5 objets. |
| Le convoyeur devrait être capable de fonctionner en continu sans interruption pendant 5 jours. | Les composants sont dimensionnés pour tenir 120 heures en continu. |
| Le convoyeur doit supporter AM et PM ainsi que 24 heures sont supportés. | L'horloge intégrée permet l'affichage au format 12h ou 24h. |
| Le convoyeur doit supporter le système métrique et impérial. | Pour la vente dans les marchés anglo-saxons, le support des kilogrammes et des livres est nécessaire. |
| Le convoyeur doit supporter le français et l'anglais. | Pour le déploiement initial en Amérique du Nord, les deux langues officielles du Canada devront être supportées. |
| L'interface usager devra supporter les langues du continent sud-américains par la suite. | Les langues officielles du Brésil et des autres pays sud-américains sont incluses. |
| Le convoyeur doit être disponible en plusieurs couleurs. | Le châssis imprimé en 3D est proposé sous différentes teintes. |
| Le convoyeur doit avoir un prix de vente d'environ 150 dollars canadiens. | Le coût de fabrication doit être d'environ 60 dollars pour faire un profit significatifs. |
| Le convoyeur doit posséder une batterie de secours pour continuer à fonctionner même en période de panne de courant. | Une batterie Li-ion prend le relais instantanément en cas de coupure secteur. |

## Améliorations prévues

| Fonctionnalités | Description |
|---|---|
| Le convoyeur devrait inclure un variateur de vitesse ajustable par l'utilisateur. | Un potentiomètre ou un menu sur l'écran permet de régler manuellement la vitesse du tapis. |
| Le convoyeur devrait détecter la couleur ou la réflectivité des objets. | Un capteur optique permet de classifier automatiquement les pièces selon leur teinte. |
| Le convoyeur devrait intégrer une détection de bourrage avec arrêt de sécurité. | Le système mesure le courant du moteur et stoppe l'entraînement si la courroie se bloque. |
| Le convoyeur devrait comporter un arrêt d'urgence physique coup de poing. | Un gros bouton rouge sécurise la ligne en coupant directement la puissance du moteur. |
| Le convoyeur devrait intégrer une caméra avec vision par ordinateur. | Une mini caméra permet de reconnaître les défauts ou la forme exacte des objets. |
| Le convoyeur devrait avoir un avertisseur sonore en cas d'erreur ou de bac plein. | Un buzzer ou un haut-parleur émet une alerte dès qu'un problème survient sur la ligne. |
| Le convoyeur devrait prendre en charge des modules d'extension de châssis. | Des rallonges de 80 millimètres permettent de rallonger la ligne selon les besoins. |
| Le convoyeur devrait sauvegarder un historique complet de la production. | Les statistiques de pesée et de comptage sont enregistrées sur une mémoire. |
| Le convoyeur devrait être compatible avec un automate industriel. | Un module d'isolation à optocoupleurs permet le couplage direct avec des systèmes industriels. |
